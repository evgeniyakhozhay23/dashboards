
# Дашборд когорты рекламных пользователей
### Источник
Karpov Courses, курс "Симулятор Аналитика", https://karpov.courses/simulator

Данные с 02.05.2026 до текущего дня (обновляются в режиме реального времени). Данные предоставлены в рамках курса, хранятся в Clickhouse.

### Структура данных
Провожу работу с данными стартапа приложения с лентой новостей (feed_actions) и мессенджером (message_actions). 

Таблица feed_actions - информация о действиях пользователей в приложении ленты новостей:
- user_id - идентификационный номер пользователя
- post_id - номер поста
- action - вид действия пользователя в ленте (категориальная переменная). Значения - like и view.
- time - дата и время действия пользователя в ленте новостей
- gender - пол пользователя
- age - возраст пользователя
- country - страна проживания пользователя
- city - город проживания пользователя
- os - операционная система устройства, с которого заходят в приложение. Значения: iOS, Android
- source - канал привлечение клиентов: ads (через рекламу), organic (самостоятельно)
- exp_group - группа пользователя для проведения эксперимента

### Используемые инструменты
- Apache Superset
### Условие задания
За последние несколько дней произошло два значительных события в продукте. Первое — крупная рекламная кампания маркетологов, в результате в приложение пришло много новых пользователей. Второе — в один из дней резко упала аудитория.
### Задачи, которые помогает решить дашборд
1. Проанализировать характер Retention пользователей, привлечённых рекламной кампанией
2. Выявить группы пользователей, которые не смогли воспользоваться лентой
### Содержание дашборда
Определено два важных события для продукта - 11 и 20 июня. 
- Графики DAU ленты в целом и в разрезах: по каналу привлечения пользователей, типу операционной системы, возрастная группа, страна.
- Выводы о динамике DAU 11 и 20 июня в зависимости от сегмента аудитории
- Тепловая диаграмма когорт пользователей с 11 июня
- Столбчатые диаграммы для сегментации пользователей когорты 11 июня по способу их привлечения, полу, типу ос, типу действия в приложении
- Выводы о судьбе данной когорты в продукте и способности приложения удержать пользователей в целом
